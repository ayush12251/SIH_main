# FRONTEND_RULES.md

Strict development rules:

- Figma is the single source of truth.
- Pixel-perfect conversion only.
- No redesign or UI improvements.
- Match fonts, colors, spacing, icons, border radius, shadows, alignment, sizing exactly.
- Reuse existing components before creating new ones.
- Tailwind only, no inline styles.
- Responsive without changing desktop design.
- Every new Figma page should follow the same design system.
